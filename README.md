🏴‍☠️ OnePieceAngular

A web application built with Angular that explores the world of One Piece.
The project displays information about characters, devil fruits, and sagas using data from a public API.

This project was created as a learning project for Angular development, focusing on components, services, routing, and API integration.

⚡ Features
🧑‍🚀 View One Piece characters
🍈 Explore Devil Fruits
📖 Browse story sagas
🔎 Dynamic data loaded from an API
🧭 Angular routing for navigation
⚙️ Modular Angular component structure

🚀 Getting Started
1️⃣ Clone the repository
git clone https://github.com/christiantenerife/OnePieceAngular.git
2️⃣ Navigate to the project folder
cd OnePieceAngular
3️⃣ Install dependencies
npm install
4️⃣ Run the Angular development server
ng serve

Then open your browser and go to:

http://localhost:4200
📡 API

This project retrieves data from a One Piece public API to display characters, fruits, and story arcs.
